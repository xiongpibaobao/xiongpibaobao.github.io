🔬 3 维交叉验证（核心创新）

  • 市级：契税 ↔ 70城房价指数 / 商品房销售面积（交易量萎缩 vs 少计收入）
  • 市级：土地增值税 ↔ 土地出让成交价款（土地财政降温 vs 清算延后）
  • 市级：企业所得税 ↔ 规上工业利润（企业利润增长 vs 应缴未缴）
  • 市级：财政收入 ↔ 全社会用电量 / 存款余额（经济活性 vs 征管问题）
  • 省级：决算收入/税收 ↔ 公报收入/税收（口径一致性核验，江苏决算=公报 7,642亿 完全吻合）
  • 省级：收入增速 ↔ GDP增速（收入弹性）、税收占比结构（60-90% 健康区间）

🚦 判定规则（让数据说话，不做主观打分）

  • 🔴 红 偏差 >30% — 严重异常；🟡 黄 5-30% — 需关注；🟢 绿 <5% — 正常
  • 异常率 = 红灯数 ÷ 可算科目数（不做打分/等级/排名）
  • 口径铁律：市本级 vs 全市、全省 vs 省本级严格分离；安徽仅省本级报表（标注说明）

「一女二嫁」多嫁图谱 —— 本维度指标的由来
「一女二嫁」= 同一份价值（土地 / 财政信用）被重复当作资源使用。现代它已演变为「一女多嫁」——同一份土地信用在闭环中被多个主体同时使用。下表列出 5 种“嫁法”及平台上对应的检测指标：
# 同一份价值“嫁”给了谁 机制 平台对应指标
①土地储备 / 棚改专项债土地出让收入作偿债来源付息占土地收入比
②一般公共预算（账本维度）政府性基金资金“调入”一般预算平衡两本预算对敲检测
③城投 / 融资平台（主体维度）城投借钱买地 → 出让金入库 → 财政返还 → 再买土地收益双重占用检测
④旧债（时间维度）新发债券中靠“再融资”偿还到期旧债借新还旧率
⑤银行 / 金融体系（金融维度）政府债务吸收本地储蓄；银行持有政府债作安全资产、土地作抵押品储蓄锁定率（债务增量÷新增存款）、债务储蓄比（债务余额÷存款余额）
为什么用“交叉信号”判定：单看任何一侧指标高企都可能是正常现象（合规发债、正常调入）；只有当两侧同时吃紧时，才说明同一笔资源在两处往返——即“一女二嫁”嫌疑。单侧高按原有维度提示，不升级。

会计层面核验：一笔财政资金的完整分录链条

🎯 为什么做这一步

前面四个指标用的是决算表的汇总数——但"同一笔钱被记两次"（一女二嫁）在汇总数上看不出来， 必须看分录的对方科目。本页把一笔钱从入库到收回、再到重新安排的全过程拆开， 给出两条支线的完整分录，作为会计层面的核验模板。

依据：《财政总会计制度》（财库〔2022〕41号，2023-01-01施行）｜历史对照：财预〔2015〕81号（已废止）｜ 地方管理层面：《湖北省省级财政结转结余资金管理办法》。全部科目与分录引自制度原文，可逐条复核。

场景设定

一笔税款 1,000 万元入库 → 安排为水利支出（农林水支出—水利工程建设）→ 其中 400 万实际使用、600 万闲置 → 收回 600 万 → 重新安排使用。

两条路的净结果完全相同，但路径相反：省以下靠"挂账不冲、重花不记"避免重复； 省以上靠"当场冲回、重花再记"避免重复。它们守的是同一条铁律—— 同一笔钱，支出只能算一次。
⚠️ 四个失真点（核验清单）
#异常操作后果核验方法
1省以下：收回后重新安排又记一次支出支出虚增600万（重复列支） 查6051贷方余额是否异常；查支出是否有无对应资金流的增加
2省以下：把闲置资金记成 6021 调入预算资金收入虚增600万 查6021的来源是否为本级收回的结转结余
3省以上：收回时不冲减支出、804104不归零支出虚增 + 804104长期挂账 查804104是否次年归零
4省以上：年末列支后、次年实际支付时又借一次支出双重列支 查"其中：权责发生制列支"与次年实际支付是否对应
⚠️ 一处制度模糊点（待考）
收回"当年拨出的款项"时存在并行规定——第四十四条（三）：
"属于应收回的拨款，应及时收回，并按收回数相应冲减支出和费用。"

这与 6051（一）"挂待处理收入、不冲减支出"的处理不同。可区分的场景：
场景适用条款处理
收回后要重新安排6051（一）～（三）挂待处理收入，后续按原/调整科目处理
年终清理中收回、不再安排第四十四条（三）直接冲减支出和费用
制度未明确划界，此点标为待考。
